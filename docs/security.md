# Security

Living document. Phase 8 performs the full review; every phase adds its mitigations here.

## OWASP Top 10 (2021) mitigations

| Risk                                           | Mitigation                                                                                                                                                                                                                                                                                                | Status                          |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| A01 Broken access control                      | Permission-based authorization middleware on every route and socket event; staff 2FA                                                                                                                                                                                                                      | Planned (Phase 2)               |
| A02 Cryptographic failures                     | Argon2id password hashing; HMAC TURN credentials; HSTS; secrets only from environment                                                                                                                                                                                                                     | Partial (HSTS, secrets)         |
| A03 Injection                                  | zod validation on every input; Mongo queries built from typed values only (never from raw request objects, which blocks operator injection)                                                                                                                                                               | Partial (validation middleware) |
| A04 Insecure design                            | Threat model per feature; rate limits; trust score; shadow bans                                                                                                                                                                                                                                           | Planned (Phase 5)               |
| A05 Security misconfiguration                  | Helmet: CSP `default-src 'none'`, `nosniff`, `X-Frame-Options: DENY`, `no-referrer`, CORP same-site; `x-powered-by` disabled; CORS locked to exact frontend origins with credentials; Scalar/OpenAPI only in development; 100 kB body limit; non-root containers; infrastructure ports bound to 127.0.0.1 | Done (Phase 1)                  |
| A06 Vulnerable components                      | Lockfile committed; `npm audit` clean; CI runs `npm ci`                                                                                                                                                                                                                                                   | Partial                         |
| A07 Identification and authentication failures | Short-lived JWT, rotating refresh tokens with reuse detection, lockout                                                                                                                                                                                                                                    | Planned (Phase 2)               |
| A08 Software and data integrity failures       | Signed anonymous tokens; verified, idempotent payment webhooks; event payloads schema-validated on publish and consume                                                                                                                                                                                    | Partial (events)                |
| A09 Logging and monitoring failures            | pino structured logs with redaction; request logs carry only id, method, URL, status; OpenTelemetry traces/metrics; immutable audit log                                                                                                                                                                   | Partial (logging, telemetry)    |
| A10 SSRF                                       | No user-controlled outbound requests; coturn denies multicast peers (private-range peer denial in production config)                                                                                                                                                                                      | Partial                         |

## Privacy

- Users' IP addresses are never returned to other users or written to logs; TURN relay-only mode hides them from peers (Phase 4).
- Video and full chat logs are never stored; only report evidence, with retention TTLs (Phase 5).
- Logs must not contain secrets, emails, IPs, fingerprints or request headers (enforced by serializers and redaction; covered by a unit test).
