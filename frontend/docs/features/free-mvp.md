# Free MVP reliability and demand validation

Core chat stays free. /pricing and /subscription show a proposed Plus price and Join Waitlist, never live checkout. The private Mongo waitlist requires a verified-email account and explicit consent, stores only account reference/time/consent version, expires logically and through TTL after 90 days, and supports immediate self-removal. No list of signups is exposed publicly or to the ordinary dashboard. No card details or paid subscription activation is involved. Billing domain, collections and test-only mock are retained as a deferred foundation; production always rejects mock confirmation and mock entitlements. No payment processor is integrated.

First-party analytics retain activity hashes up to 90 days and daily activity/matching/session/RTC data for 35 days. UTC-day metrics are shown on /admin with existing permission/MFA checks. Daily active users count authenticated anonymous/account sessions, not all landing-page visitors. Changing anonymous identity can count again. Average waits are aggregate; p95 uses the latest 2,000 daily waits. RTC rate uses first client-reported terminal setup outcome per session/participant, not independent network measurement. Concurrent presence is provided by the existing dashboard. Waitlist conversion is active 90-day signups divided by unique authenticated 90-day previews, not a revenue forecast. No conversation contents enter analytics.

ADULT_CHAT_ENABLED defaults false and is enforced at the server gateway. Even enabling that flag cannot bypass the unavailable age provider. Age status is separate from self-attestation. Provider-approved onboarding, callback verification/revocation, legal jurisdiction and real-world safety operations remain release gates.

New reports contain durable incomplete workflow markers. Worker recovery scans them every 10 seconds, so failed broker publication or trust/enforcement effects can retry without duplicate per-report trust deductions. Effect IDs remain in trust documents to prevent replay; monitor document growth before high-volume rollout. Legacy scored reports are treated as already complete; new recovery does not silently reapply their effects. Required indexes gate startup. WebSocket transport is explicit. See workspace docs/LOW_COST_LAUNCH.md for resource limits, bandwidth formula, SMTP and backup/restore requirements. No public deployment or expenditure was performed.

Environment: PAYMENT_PROVIDER=none (default); PLUS_PRICE_MINOR=999 seeds the plan, while admin price changes affect new subscriptions only; MOCK_PAYMENT_WEBHOOK_SECRET is isolated-test-only and forbidden in production; ADULT_CHAT_ENABLED=false. Existing env files are not overwritten. The production overlay pins both payment and Adult gates closed. Prices are proposed previews; changes do not charge anyone.
